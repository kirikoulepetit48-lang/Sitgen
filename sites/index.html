Comment déployer ce backend :
1. Crée un compte gratuit sur render.com (ou railway.app)
2. Crée un nouveau "Web Service" et importe ce code (via GitHub, comme tes autres projets)
3. Ajoute tes vraies valeurs secrètes dans les "Environment Variables" du tableau de bord (jamais dans le code publié)
4. Render te donne une URL publique (ex: tonapp.onrender.com) — c'est cette URL que tes sites HTML pourront appeler
